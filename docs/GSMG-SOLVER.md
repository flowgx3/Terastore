# TERA GSMG SOLVER

بوت Discord مخصص حصرياً لتحليل لغز GSMG.IO 5 BTC.

## أوامر Discord
- `/gsmg status` — حالة وحدات التحليل.
- `/gsmg matrix` — إعادة استخراج شبكة 14×14.
- `/gsmg sha256` — حساب SHA-256 للنص كما أُدخل، دون حذف المسافات أو تغيير حالة الأحرف.
- `/gsmg decrypt` — فك OpenSSL AES-256-CBC salted Base64؛ يمكن إرفاق ملف نصي للـBlob الطويل.
- `/gsmg beaufort` — تجربة Beaufort بالمفتاح المحدد.

## إعداد الاستضافة الحالية
لا تنشئ تطبيق Discord جديداً ولا تضف أسماء متغيرات جديدة. استعمل المتغيرات الموجودة نفسها:
- `DISCORD_TOKEN`
- `CLIENT_ID`
- `GUILD_ID` (اختياري)

لا يحتاج المشروع قاعدة بيانات PostgreSQL.

## التشغيل
أمر التشغيل: `npm start`

التحقق: `npm run verify`

الناتج المتوقع من اختبار الشبكة: `gsmg.io/theseedisplanted`.

## منهجية العمل
نحفظ المدخلات الأصلية كما هي، ونوثق كل تحويل ومعاملاته. لا نعتبر أي فرضية حلاً إلا بعد إعادة إنتاجها والتحقق منها بصورة مستقلة.
